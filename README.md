# ハテナリア

ホームアイランドを玄関にして、教科ごとの島（学習アプリ）を気球でめぐる学習サイトです。
公開アドレス（予定）：https://hatenaria.github.io/
共通規格の正本は「学習アイランド 共通仕様書」、設計の詳細は「ホームアイランド 設計書」を見てください。

## フォルダ

| 場所 | 中身 |
| --- | --- |
| `index.html` | ホームアイランド v0.2.1（島を歩く・掲示板・気球の島めぐり。小窓はキーボード・タッチでも操作できる） |
| `home/` | ホームアイランドのプログラムと設定（`data.js` に建物・島・お知らせ） |
| `manifest.json` | 「ホーム画面に追加」の設定（サイト全体で1つ） |
| `common/` | 共通部品（変更はホームアイランドの開発チャットで行う） |
| `test/sample/` | つなぎ口の動作を確かめる試験用アプリ（島めぐりの「ためしの しま」） |
| `test/books.html` | 共通部品の試験ページ（冒険の書の管理） |

## 共通部品 版 0.1.1

| ファイル | 役割 |
| --- | --- |
| `common/store.js` | 端末への保存（IndexedDB `gakushu-island`、保存場所 `kv`） |
| `common/books.js` | 冒険の書（3冊まで、p1〜p3） |
| `common/book-picker.js` | 冒険の書を選ぶ・作る・消す画面 |
| `common/island-api.js` | 島とアプリをつなぐ本体（コイン・素材・学習記録） |
| `common/island-link.js` | 各アプリに貼り付ける「つなぎ口」 |

## 既存アプリを島につなぐ手順

1. `common/island-link.js` の中身を、アプリの `<script>` の先頭に貼り付ける。
2. アプリの起動時に `await Island.init({ appId: 'アプリ名', subject: '教科' })` を呼ぶ。
3. 学習のひと区切りごとに `Island.reward(取り組んだ量)` と `Island.record(要約)` を呼ぶ。
4. アプリを島のフォルダ（例 `math/keisan/`）に置き、`commonPath` を共通部品の場所に合わせる（例 `'../../common/'`）。

単独で開いたとき（Claude のリンク、別のサイト、ファイルを直接開く）は自動で「単独モード」になり、今までどおり動きます。

## 守ること

- `localStorage` は使わない。`localStorage.clear()` は絶対に使わない（同じオリジンの別アプリの保存を消してしまうため）。
- データベースの版番号（`DB_VERSION`）は変えない。保存場所は `kv` 1つだけ。
- 児童の実名は扱わない。
